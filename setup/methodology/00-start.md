# 00 — Старт CTF: первые 10 минут

> Это процедура, а не теория. Теория — в `CTF_CHEATSHEET.md`. Иди по шагам сверху вниз.

## 1. Окружение (до старта, 1 раз)

```bash
setup/install.sh -y --with-wordlists     # прибитые бинарники + SecLists
setup/install.sh --check                 # чего не хватает из Kali-тулзов
```

Проверь, что есть VPN/сеть до платформы, открой таймер соревнования, попроси у орга
формат флага (`flag{...}` / `CTF{...}`) и правила (что запрещено).

## 2. Воркспейс на каждое задание

```bash
ctf-init web-login      # создаёт files/ loot/ scripts/ notes.md
cd web-login
```

Правило: **один таск — одна папка**. Файлы задания кладём в `files/`, ничего не удаляем.
Весь инструментальный вывод `enum-*.sh` сам падает в `loot/`.

## 3. Первое чтение задания

1. Категория (web/pwn/rev/crypto/forensics/misc/osint/network).
2. Очки — грубая оценка сложности.
3. Формат дано: URL, `nc host port`, файл, картинка, описание-загадка.
4. Скрытые подсказки в описании: имена, аббревиатуры, «формат», авторы, ссылки.
5. Скачай **все** вложения сразу и посчитай хэши: `sha256sum files/*`.

## 4. Триаж "с чем имеем дело"

| Что дано | Первый шаг |
| --- | --- |
| URL / веб-приложение | категория → `methodology/web.md` |
| `nc host port` | `nc -v host port`, баннер → `methodology/pwn.md` или `network.md` |
| ELF/PE/APK/JAR | `enum-bin files/chall` → `methodology/rev.md` |
| pcap / дамп / диск | `enum-file files/capture.pcap` → `forensics.md` |
| числа, ключи, `cipher.txt` | `crypto.md` |
| ник/фото/домен/аккаунт | `osint.md` |
| что-то странное | `misc.md` |

## 5. Разделение работы в команде

- Каждое задание берёт **один** человек; второй подключается только если первый встал >20 мин.
- Решённое фиксируем в `notes.md` сразу: команда, вывод, флаг.
- Не решаем вслепую: сначала 5 минут на поиск в поисковике («<ключевые слова> CTF writeup»).
- Первый blood — только если задача действительно быстрая; иначе выгоднее закрыть
  много средних задач.

## 6. Заметки (обязательно!)

В `notes.md` пиши **каждую** попытку одной строкой:

```
- [14:05] SQLi в /login (user=admin'-- ) -> 500, но другая страница
- [14:12] /api/users/1 -> IDOR, отдал другого юзера
```

Почему: тупики экономят время (не пробуешь заново), а в конце из заметок
за 5 минут собирается райтап.

## 7. Когда количество попыток зашкалило

1. Перечитай описание — 80% «фейлов» это игнорированный хинт.
2. Смени ось: статика → динамика, чёрный ящик → исходники, локально → удалённо.
3. Спроси команду / поисковик / AI (в этом репо есть `setup/ai-setup.sh` — OpenCode + REA).
4. Отложи на 30 минут и возьми другую задачу. Вернись с свежей головой.

## 8. Флаг и после флага

- Проверь формат до отправки; пробелы и переводы строк — убирай (`tr -d '\n'`).
- Сразу после решения напиши в команду: **что** дало флаг (одно предложение).
- Держи `scripts/` в воркспейсе — это ваш райтап.
- Не удаляй `loot/` до конца CTF.
